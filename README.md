# 🎨 ART BEAT — Where Paint Splatters Meet Pure Rhythm!

A vibrant, joyful creative studio website designed for kids to explore art and music. Built with HTML, Tailwind CSS, and the playful "Candy" design system.

## 🚀 Getting Started

### Open Locally
Simply open `art_beat_kids_enthusiasts_art_music_wonderland/code.html` in your browser.

### With a Local Server
```bash
cd art_beat_kids_enthusiasts_art_music_wonderland
python3 -m http.server 8000
```
Then visit `http://localhost:8000/code.html`

## 📁 Project Structure

- **`code.html`** - Main website (all-in-one HTML file with embedded CSS)
- **`candy/`** - Design system documentation and visual guidelines
- **Images/** - Photography and brand assets for the studio

## 🎨 Design System: Candy

Bold, fun, playful design with:
- Hot pink (`#e040a0`), purple (`#9b51e0`), cyan (`#00c2ff`) primary colors
- Pill-shaped buttons and rounded elements
- Bouncy, spring-like microinteractions
- DM Sans and Fredoka typography

See `candy/DESIGN.md` for complete design specs.
